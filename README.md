# Simulação de Quishing (Treinamento de Cybersegurança)

Este projeto contém uma página web interativa de conscientização sobre segurança (Quishing - Phishing via QR Code) para treinamentos corporativos.

## Como utilizar
1. Hospede este repositório (via GitHub Pages, Netlify, etc.).
2. Gere um QR Code apontando para o link da página hospedada.
3. Cole o QR Code nos materiais do treinamento.
